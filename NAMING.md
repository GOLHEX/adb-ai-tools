# Именование файлов при генерации

## Зачем это нужно

Имя файла — единственное, что связывает работу в портфеле с тем, как и когда она была
сделана. Adobe хранит его в поле `originalName` и отдаёт через листинг портфеля, поэтому
по имени можно поднять всю историю работы, не заводя отдельную базу.

Что сейчас в портфеле:

| шаблон | работ | что можно узнать из имени |
|---|---:|---|
| `20250404_06802.jpeg` | ~3 076 | только дату генерации |
| `Project_20250404_00123` | ~668 | дату |
| `8K_17x10_00596_.png` | ~157 | размер и пропорции |
| `8k_g_20250404_00048.png` | ~69 | дату |

Тема, модель, промпт-серия — нигде. Поэтому связать «что сгенерировано» с «что продалось»
можно только вручную, глядя на картинку. Именно на это и ушёл весь разбор контактных листов.

## Формат

```
ГГГГММДД_тема_подтема_соотношение_NNN.png
```

Пример: `20260826_finance_tuition_16x9_004.png`

| часть | правила |
|---|---|
| `ГГГГММДД` | дата генерации, без разделителей |
| `тема` | из справочника ниже, латиница, без пробелов |
| `подтема` | конкретный сценарий: `tuition`, `travel`, `pension`, `datebreach` |
| `соотношение` | `16x9`, `1x1`, `9x16`, `21x9`, `4x5` |
| `NNN` | порядковый номер внутри серии, с ведущими нулями |

Длина укладывается в лимит Adobe (30 символов на имя в CSV-импорте — при необходимости
сокращать подтему, но не дату и не тему).

## Справочник тем первого уровня

`finance` · `security` · `medical` · `logistics` · `energy` · `realestate` · `education`
`sport` · `food` · `retail` · `template` · `texture` · `season` · `people` · `nature`

`template` — отдельная тема для заготовок под чужой контент: пустые вывески, бирки,
рамки, подиумы, фоны с местом под текст. По данным `THEMES.md` это самая доходная группа
на одну работу, поэтому она выделена, а не размазана по остальным.

## Правило количества

В имени зашита подтема — это и есть счётчик разнообразия. **На одну пару тема+подтема
делается не больше двух работ за партию.** Третья и далее почти гарантированно получат
`Similar auto rejected` либо утонут в выдаче рядом со своими же сёстрами.

Проверка перед заливкой: сгруппировать имена по `тема_подтема` и убедиться, что нигде
не больше двух файлов. Это одна строка кода и она отсекает основную причину отказов.

## Что это даёт через полгода

Выгрузка продаж содержит колонку `filename`. При таком именовании доход раскладывается
по темам и подтемам одной группировкой, без разбора картинок глазами. Вопрос
«что генерировать дальше» перестаёт быть предметом обсуждения и становится запросом к данным.
